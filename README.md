# Własności liczb naturalnych (klasa 5)

Strona do nauki: wielokrotności i NWW, dzielniki i NWD, cechy podzielności, liczby pierwsze i złożone oraz rozkład na czynniki pierwsze.

- **Strona:** https://wmocek.github.io/nwd-nww/
- Animacje zrobione w Manim (`manim_scenes.py`)
- Testy do każdego działu i test zbiorczy – przy każdym wejściu losują się nowe zadania
- Karty pracy do druku lub do pisania na iPadzie: [`Wlasnosci_liczb_naturalnych_karty_pracy.pdf`](Wlasnosci_liczb_naturalnych_karty_pracy.pdf) (źródło LaTeX: pliki `.tex`, kompilacja: `xelatex main.tex`)

## Zapisywanie wyników testów (opcjonalnie)
Plik `apps_script_wyniki.gs` wklej do Apps Script w swoim arkuszu Google i wdróż jako aplikację internetową. Adres `/exec` jest wpisany w `index.html` (`const RESULTS_URL`). Pusty adres wyłącza wysyłanie.
